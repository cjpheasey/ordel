# Ordel brand guide

**Ordel** (OR-dell), from *order*: every plugin in its place.

## The symbol

Eight tiles and one ring. The tiles are your library, sorted; the brass ring is the plugin you came for. The ring is the one detail that carries the idea, so it is always brass and never replaced.

| File | Use |
|---|---|
| `final/ordel-symbol.svg` | On light backgrounds (ink tiles, brass ring) |
| `final/ordel-symbol-reversed.svg` | On dark backgrounds (ivory tiles, brass ring) |
| `final/ordel-app-icon.svg` | App icon, README, store listings |
| `final/ordel-symbol-small*.svg` | 24 px and below: the ring becomes a solid brass tile |
| `final/ordel-symbol-small-black.svg` | One colour at small sizes: the centre slot is left empty |
| `final/ordel-symbol-black.svg`, `-white.svg` | One-colour print, embossing, single-colour overlays |

## The wordmark

`ordel`, always lowercase, drawn from circles and strokes (it is not a font). Its signature is the **e**'s crossbar running on into the **l**, in brass.

| File | Use |
|---|---|
| `final/ordel-wordmark.svg` / `-reversed.svg` | Name on its own |
| `final/ordel-lockup-horizontal*.svg` | Symbol + name side by side: headers, title bars, README |
| `final/ordel-lockup-stacked*.svg` | Symbol above name: splash screens, square spaces |

Never retype the name in a font to stand in for the wordmark, and never stretch, outline or recolour it.

## Colour

| Name | HEX | RGB | Role |
|---|---|---|---|
| Ink | `#14171F` | 20 23 31 | Base: backgrounds, app icon tile, text on light |
| Ivory | `#ECE6D8` | 236 230 216 | Tiles and text on dark |
| Brass | `#C9A15A` | 201 161 90 | The accent: the ring and the crossbar only |
| Paper | `#F4F2EE` | 244 242 238 | Light backgrounds |

Brass is an accent, not a fill. Use it for one thing at a time. Ivory on Ink and Ink on Paper both pass WCAG AA for text; Brass on Ink is for marks and large type, not body text.

## Clear space and minimum size

- **Clear space:** at least one tile width (24 % of the symbol's height) on every side.
- **Minimum sizes:** symbol 16 px (use the small cut at 24 px and below); horizontal lockup 96 px wide; wordmark 64 px wide.

## Don't

- Don't rotate the grid, change the tile count, or move the ring out of the centre.
- Don't add gradients, shadows, glows or outlines.
- Don't place the colour symbol on busy photos; use the one-colour version on a solid area instead.

## Open items

- The wordmark's curves are stored as fine straight segments; redraw with true arcs before large-format print.
- A professional trademark search for "Ordel" (UK IPO / EUIPO) before public launch.
